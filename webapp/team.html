About

Project Context

📄

Research Paper

"Reinforcement Learning for Wordle: A DQN-Based Decision Support System for Optimal Word Guessing"

This project implements a complete RL pipeline to solve Wordle, comparing a trained embedding-based DQN agent against a near-optimal entropy-greedy heuristic baseline.

🎓

Course

Reinforcement Learning — Final Project

The project covers MDP formulation, Deep Q-Networks, Double DQN, Prioritized Experience Replay, curriculum learning, and comprehensive benchmarking.
