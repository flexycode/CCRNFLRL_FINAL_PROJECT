# Implementation Coverage & Test Matrix

## Architecture Coverage

| Component | File | v1 Status | v2 Status | Changes |
|-----------|------|-----------|-----------|---------|
| Word encoding | `core/wordle_mdp.py` | N/A | ✅ New | `encode_word()`, `encode_word_batch()` |
| State encoder | `core/dqn_agent.py` | MLP 183→256→256→N | ✅ Revamped | EmbeddingQNetwork: state+word → Q-value |
| Replay buffer | `core/dqn_agent.py` | Uniform 50K | ✅ Revamped | Prioritized 200K + uniform fallback |
| Target network | `core/dqn_agent.py` | Hard copy | ✅ Revamped | Soft (Polyak) + periodic hard update |
| Action selection | `core/dqn_agent.py` | ε-greedy over fixed indices | ✅ Revamped | ε-greedy over word feature embeddings |
| Action masking | `core/wordle_env.py` | Python loop | ✅ Optimized | Vectorized NumPy arrays |
| Reward shaping | `core/wordle_env.py` | -1 + info_gain + terminal | ✅ Enhanced | Progressive solve bonus |
| Board renderer | `core/board_renderer.py` | ✅ Working | ✅ Unchanged | No changes needed |

## Test Commands

```bash
# Quick smoke test (should complete in ~5 minutes)
python training/train.py --n_words 200 --episodes 500

# Full training with curriculum
python training/train.py --n_words 2309 --episodes 3000 --curriculum

# Benchmark (in-distribution)
python training/benchmark_dqn.py --n_words 200

# Benchmark (with OOD)
python training/benchmark_dqn.py --n_words 200 --ood

# Comparison
python training/compare.py --n_words 200

# Generate all results
python analysis/generate_results.py
```
